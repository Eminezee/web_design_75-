LUMIÈRE HOTEL — PROJECT FINAL WEB DESIGN (75% DEVELOPMENT)
========================================================

DESKRIPSI
Website hotel fiktif dengan 15 halaman yang saling terhubung. Dibangun menggunakan HTML5, CSS3, Bootstrap 5.3.3, dan JavaScript. Versi ini merupakan prototipe frontend untuk demonstrasi proyek final.

DAFTAR HALAMAN
1. index.html             — Beranda
2. rooms.html             — Daftar kamar
3. room-detail.html       — Detail kamar
4. facilities.html        — Fasilitas hotel
5. dining.html            — Restoran
6. spa.html               — Spa & wellness
7. gallery.html           — Galeri foto (klik foto untuk memperbesar)
8. offers.html            — Penawaran
9. about.html             — Tentang hotel
10. contact.html          — Kontak dan formulir pesan demo
11. booking.html          — Form pemesanan dan estimasi biaya
12. payment.html          — Ringkasan dan simulasi pembayaran
13. booking-success.html  — Konfirmasi pemesanan demo
14. reviews.html          — Ulasan tamu
15. faq.html              — Pertanyaan umum

FITUR YANG SUDAH DIIMPLEMENTASIKAN
- Navigasi konsisten antar 15 halaman dan layout responsif Bootstrap.
- Pemilihan kamar dari halaman daftar menuju formulir pemesanan.
- Validasi data pemesan, tanggal check-in/check-out, dan durasi menginap.
- Kalkulasi total harga berdasarkan tarif kamar dan jumlah malam.
- Penyimpanan sementara data booking menggunakan localStorage.
- Ringkasan booking, pilihan metode pembayaran, dan alur pembayaran simulasi.
- Kode konfirmasi demo pada halaman sukses.
- Form kontak dengan feedback pada sisi browser.
- Galeri foto dengan lightbox dan dukungan keyboard.
- State focus yang lebih jelas, reduced-motion support, dan lazy loading gambar.

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder Lumiere_Hotel_15_Pages.
3. Jalankan index.html menggunakan browser modern (Chrome, Edge, Firefox).
4. Internet diperlukan untuk Bootstrap CDN, Google Fonts, dan foto Unsplash.

STATUS 75% — BATASAN YANG BELUM SELESAI
- Belum memiliki backend, database, autentikasi, atau panel admin.
- Pemesanan hanya disimpan di browser pengguna (localStorage), bukan server.
- Pembayaran hanya simulasi; tidak ada transaksi uang sungguhan atau payment gateway.
- Form kontak belum mengirim email/server request.
- Konten, alamat, harga, ulasan, dan identitas hotel masih berupa data demonstrasi.
- Belum dilakukan deployment hosting dan pengujian lintas perangkat/browser secara menyeluruh.

CATATAN PENGEMBANGAN
Persentase 75% merupakan target/status pengembangan prototipe frontend, bukan hasil pengukuran otomatis. Untuk menjadi sistem produksi, tahap berikutnya adalah backend/API, database, autentikasi, payment gateway, validasi server-side, serta pengujian dan deployment.
